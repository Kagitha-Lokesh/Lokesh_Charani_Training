        DOM represents an HTML docs as a tree of nodes.
        The DOM provides functions that allow to add,removemmodify of the document effectively.

        In the DOM  tree
             Document ---> root tree
                          one child node --> HTML (document element)

        node has 2 properties nodeName, nodeValue


        constant                    nValue       Description

        Node.PROCESSING_INSTRUCTION_N0DE 7          A processing Instruction
        Node.COMMENT_NODE               8           A comment Node
        Node.DOCUMENT_NODE              9           A Document Node
        Node.DOCUMENT_TYPE_NODE         10          DOCTYPE
